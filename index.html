Developer Setup

开发工具接入

为 Codex CLI 和 Claude Code 配置 Xi Xu's AI Inference。脚本会先备份现有配置，API Key 仅保存在当前用户目录。

Codex CLI

Linux / macOS

bash <(curl -fsSL https://api.xi-xu.me/setup/codex.sh)

Windows PowerShell

powershell -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((New-Object System.Net.WebClient).DownloadString('https://api.xi-xu.me/setup/codex.ps1')))"

查看 codex.sh · 查看 codex.ps1

Claude Code

Linux / macOS

bash <(curl -fsSL https://api.xi-xu.me/setup/claude.sh)

Windows PowerShell

powershell -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((New-Object System.Net.WebClient).DownloadString('https://api.xi-xu.me/setup/claude.ps1')))"

查看 claude.sh · 查看 claude.ps1

运行远程脚本前可以先打开对应链接检查内容。重新运行安装脚本会更新接入配置，并为原文件创建带时间戳的备份。
API Base URL：https://api.xi-xu.me/v1
